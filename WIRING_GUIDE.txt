QUICK START WIRING GUIDE
========================

This is a simplified, visual guide for connecting the LED blinker circuit.
For complete details, see CIRCUIT_DIAGRAM.txt


COMPONENTS NEEDED:
------------------
[ ] Arduino Uno (or compatible)
[ ] IRLZ44N MOSFET (logic-level N-channel) - RECOMMENDED
[ ] 5mm LED (any color)
[ ] 220Ω resistor (for MOSFET gate)
[ ] 470Ω resistor (for LED current limiting, adjust based on your LED)
[ ] Breadboard
[ ] Jumper wires (male-to-male)
[ ] 9-12V power supply or battery (for LED power)
[ ] USB cable (for Arduino programming)


STEP-BY-STEP WIRING:
--------------------

Step 1: Place MOSFET on breadboard
-----------------------------------
Looking at the flat face of the MOSFET (TO-220 package):

        +-----+
        | TAB |  ← This is the metal tab (connected to Drain)
        +-----+
        | | | |
        +-+-+-+
         1 2 3
         | | |
         G D S

    G = Gate (Pin 1, left)
    D = Drain (Pin 2, middle) 
    S = Source (Pin 3, right)

Insert MOSFET into breadboard with legs in separate rows.


Step 2: Arduino to MOSFET Gate
-------------------------------
┌────────────┐
│  ARDUINO   │
│            │
│   PIN 9 ───┼──────[220Ω]────→ MOSFET Gate (Pin 1)
│            │
└────────────┘


Step 3: MOSFET Source to Ground
--------------------------------
MOSFET Source (Pin 3) ──→ Breadboard Ground Rail (-)


Step 4: Arduino Ground to Breadboard
-------------------------------------
┌────────────┐
│  ARDUINO   │
│            │
│   GND ─────┼──→ Breadboard Ground Rail (-)
│            │
└────────────┘


Step 5: LED Connection
-----------------------
LED has two legs:
  - LONG leg = Anode (+)  ← Connect to POSITIVE
  - SHORT leg = Cathode (-) ← Connect to MOSFET Drain

Connection:
    LED Cathode (short leg) ──→ MOSFET Drain (Pin 2)


Step 6: LED Current-Limiting Resistor
--------------------------------------
    Power Supply (+) ──→ [470Ω Resistor] ──→ LED Anode (long leg)


Step 7: Power Supply Ground
----------------------------
    Power Supply (-) or GND ──→ Breadboard Ground Rail (-)

⚠️ CRITICAL: Arduino GND, Power Supply GND, and MOSFET Source
             MUST ALL be connected to the same ground rail!

POWER UP SEQUENCE:
==================
1. Double-check ALL connections
2. Plug in Arduino USB (powers Arduino only)
3. Upload the code (led_blinker.ino or simple_blink.ino)
4. Connect external power supply (9-12V) - LED should start blinking
5. Open Serial Monitor (9600 baud) to see status messages


TESTING CHECKLIST:
==================
Before powering on:
[ ] All grounds connected together
[ ] LED polarity correct (long leg to +)
[ ] MOSFET pins correctly identified
[ ] 220Ω resistor between Arduino Pin 9 and MOSFET Gate
[ ] 470Ω resistor between power supply and LED anode
[ ] No short circuits

After code upload:
[ ] LED blinks with fluorescent-like behavior
[ ] Serial monitor shows status messages
[ ] MOSFET doesn't get hot (if it does, check for shorts)


TROUBLESHOOTING:
================
LED doesn't turn on:
  → Check LED polarity (flip it around)
  → Verify MOSFET is logic-level type (IRLZ44N recommended)
  → Check all ground connections

LED always on:
  → Check code uploaded correctly
  → Verify Pin 9 connection
  → Test with simple_blink.ino first

LED very dim:
  → MOSFET may not be fully turning on
  → Use logic-level MOSFET (IRLZ44N)
  → Check gate voltage with multimeter (should be ~5V when on)

Serial monitor shows gibberish:
  → Set baud rate to 9600
  → Disconnect and reconnect Arduino
