PROJECT SUMMARY
===============

LED Blinker with Fluorescent Light Simulation
----------------------------------------------

This Arduino project provides complete code and wiring instructions for controlling
an LED with a MOSFET, featuring a realistic fluorescent light startup simulation.


FILES IN THIS REPOSITORY:
--------------------------

1. led_blinker.ino
   - Main Arduino sketch with fluorescent simulation
   - Three-phase startup: rapid flickers, warmup, stabilization
   - PWM brightness control for realistic effects
   - Configurable timing parameters
   - Serial debug output

2. simple_blink.ino
   - Basic test sketch for verifying hardware
   - Simple on/off blinking (1 second intervals)
   - Useful for troubleshooting the circuit

3. README.md

   - Components list with specifications

   - Installation and usage instructions
   - Configuration guide

KEY FEATURES:

✓ Realistic fluorescent light simulation

CIRCUIT OVERVIEW:
-----------------

Arduino Pin 9 (PWM) → [220Ω resistor] → MOSFET Gate
MOSFET Drain → LED Cathode (-)
MOSFET Source → Ground
LED Anode (+) → [Current-limiting resistor] → Power Supply (+)
All grounds connected together (Arduino GND, PSU GND, MOSFET Source)


RECOMMENDED COMPONENTS:
-----------------------

- Arduino Uno/Nano
- IRLZ44N N-Channel MOSFET (logic-level)
- 220Ω resistor (gate protection)
- 470Ω resistor (LED current limiting, adjust for your LED)
- 5mm LED or high-power LED
- 9-12V power supply
- Breadboard and jumper wires


USAGE:
------

1. Wire the circuit according to WIRING_GUIDE.txt
2. Test with simple_blink.ino first
3. Upload led_blinker.ino for fluorescent effect
4. Open Serial Monitor (9600 baud) to see status
5. Customize timing in code as desired


CUSTOMIZATION:
--------------

All timing parameters are configurable in led_blinker.ino:
- STARTUP_FLICKERS: Number of initial flickers
- FLICKER_MIN_TIME / FLICKER_MAX_TIME: Flicker duration range
- WARMUP_FLICKERS: Warmup phase iterations
- STABLE_DURATION: How long LED stays on
- OFF_DURATION: How long LED stays off between cycles


SAFETY NOTES:
-------------

⚠️ Use logic-level MOSFET (IRLZ44N) for Arduino compatibility
⚠️ Connect all grounds together (common ground is critical)
⚠️ Verify LED polarity before powering on
⚠️ Use appropriate current-limiting resistor for your LED
⚠️ High-power LEDs require heatsinks on LED and MOSFET
⚠️ Never look directly at high-power LEDs
